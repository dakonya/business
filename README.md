# dakonya portfolio

Personal portfolio for Daniyar Adylbekov, deployed on Vercel.

## Local preview

Serve the repository root with any static HTTP server, for example:

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

## Deployment

The project is a buildless static site. Connect the repository to Vercel with the
framework preset set to **Other** and leave the build and output directory fields
empty.
